# Accounts & Access

This page describes how to get access to GIRAF services and accounts.

## Password Management

All relevant passwords are stored in [KeePass](https://keepass.info/). Contact Ulrik Nyman ([ulrik@cs.aau.dk](mailto:ulrik@cs.aau.dk)) to get the `.kbdx` file.

**Best practices:**
- Store the file on Google Drive so all team members can access it
- The SM group should manage the password file
- Re-upload after any changes

## GitHub

The [GIRAF GitHub organization](https://github.com/aau-giraf) contains all repositories.

**To get access:**
1. Contact an existing owner to be added
2. Or use the shared account (requires 2FA code from Ulrik):
   - Username: `giraf@lists.aau.dk`
   - Password: see KeePass

## Google Play Store

For publishing Android apps.

- Email: `aaugiraf@gmail.com`
- Password: see KeePass

## App Store

For publishing iOS apps.

- Email: `giraf@lists.aau.dk`
- Password: see KeePass

## Server Access

As of September 2025, there is no central GIRAF server running. Previous semesters used [AAU Strato](https://hpc.aau.dk/strato/) for hosting.

Check with your supervisor about current infrastructure needs.
